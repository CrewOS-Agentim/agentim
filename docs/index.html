Ideas & projects

Pitch it in a group chat.
A team checks it, plans it and builds it.

A new idea, a new project, or a feature for your existing code. Agents that act like real employees check it's worth building, turn the goal into a graph of tasks, check each other's work, and keep going, in minutes, not days. Built on three layers: a harness (team memory and permissions), loops (every result checked against evidence that can fail) and graphs (parallel tasks with gates).

💡

Pitch it in a chat

New chat → Pitch an idea: Agent Tim asks 10 questions one at a time (AI can suggest answers), then your leadership agents discuss it with each other.

🔎

Worth building?

Every project starts with its goal, then a check: who already solves it, build vs buy, and the gap. With Claude Code it's real web research. You decide: build anyway, or stop.

🗺️

Goals become graphs

Agent Tim turns a goal into tasks with dependencies. Independent tasks run in parallel, each starts from the results it needs, and passed work is frozen.

🔁

Checked, not trusted

Every task has a “done when”. Tim checks each result on a different model than the one that did it; fails go back with the reason, and repeated failures become lessons.

⏱️

Tim runs the loop, in minutes

Every minute Tim keeps work moving, asks each owner for an ETA in minutes, chases anything late, and reminds you about approvals. A Gantt chart shows planned vs actual.

🙋

Gates you control

Anything public, sent to customers, costing money or deploying waits for you. Autopilot keeps building until it's developed; Claude Code writes the code and your tests prove it.

🧲

A recruiter that reads code

Describe a role; the Recruiter reads engineers' GitHub repos and commits and drafts a personal LinkedIn note for each. You review and send it yourself.

💬

Messages, like iMessage

The team room, your own groups, and a private 1:1 with any agent. Summaries on demand, or every few minutes.

🤖

Claude through tmux, not the API

Claude Opus, Sonnet and Haiku run with claude -p in background terminal sessions (tmux) on your login: no API key, and you can watch any session. Or switch to an API key.

🚀

Design → code → live

The Launch tab builds, tests, versions (v0.1.0 → …) and deploys to Vercel, Netlify, Cloudflare, Fly.io or Docker, then checks the URL is live.

Get started

Up and running
in five minutes.

Open the Mac app

Onboarding installs Docker if needed, lets you pick chat, coding, voice and video models, and sets everything up. It's the whole quick start. Prefer the terminal? Read on.

git clone https://github.com/CrewOS-Agentim/agentim.git && cd agentim
brew install xcodegen && xcodegen generate && open agentim.xcodeproj   # ⌘R

…or get the code

You need a Mac with Apple silicon and Docker Desktop.

git clone https://github.com/CrewOS-Agentim/agentim.git
cd agentim

Make it always-on

Creates .env with fresh secrets, then installs the restart watchdog, the LTX runner and the lid-close power guard. It asks for your password once.

./deploy/macos/install.sh

Connect your chats

Add a Telegram bot token from @BotFather and/or Slack tokens to .env, plus who's allowed to talk to Tim. For WhatsApp, scan the QR at localhost:3000/dashboard.

open -e .env
docker compose up -d   # Hugging Face models download on first start

Connect the app

Build it once with Xcode and drag it to Applications. Then in This Mac, click Connect this Mac's models.

brew install xcodegen && xcodegen generate
open agentim.xcodeproj   # ⌘R

Say hi 👋

Message your bot. Try /help, /agents, /validate-your-startup my idea… or /video a cat surfing at sunset.
